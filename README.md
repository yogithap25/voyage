# 🌍 VOYAGE

A modern travel planning web application that helps users plan trips, compare transport options, discover hotels, split travel expenses, and access emergency travel resources—all from one platform.

## ✨ Features

- 🗺️ Smart Trip Planner
- 🏨 Hotel Discovery & Booking
- 🚌 Transport Cost Comparison
- 🍽️ Nearby Restaurant Finder
- 💰 Group Budget Splitter
- 🛡️ Safety Hub with Emergency SOS
- 👤 User Authentication
