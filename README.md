# 🌍 VOYAGE

A modern travel planning web application built with **Django** that helps users plan trips, compare transport options, discover hotels and restaurants, split travel expenses, and access emergency travel resources—all from one platform.

---

## ✨ Features

- 🗺️ AI-inspired Trip Planner
- 🏨 Hotel Discovery & Booking
- 🚌 Transport Cost Comparison
- 🍽️ Nearby Restaurant Finder
- 💰 Group Budget Splitter
- 🛡️ Travel Safety & Emergency Contacts
- 👤 User Authentication (Login & Signup)

---

## 🛠️ Tech Stack

- **Backend:** Django (Python)
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** SQLite
- **Authentication:** Django Authentication System
- **API:** Google Maps API
- **Version Control:** Git & GitHub

## 📸 Application Modules

- Home
